1. Document Structure Tags

These tags define the basic structure of an HTML document.

<html> - Root Element

Purpose: The root element that wraps all content on the page.

<html lang="en">...</html>

<head> - Document Metadata

Purpose: Contains metadata, title, links to CSS, and scripts.

<head><title>Page Title</title></head>

<body> - Document Body

Purpose: Contains all visible content on the page.

<body>Your visible content here</body>

<meta> - Metadata

Purpose: Defines metadata like character set, viewport, description.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

2. Text Formatting Tags

These tags are used to format and style text content.

Heading Tags: <h1> to <h6>

Purpose: Define headings, with h1 being the largest and h6 the smallest.

This is H1 - Main Heading

This is H2 - Subheading

This is H3 - Smaller Subheading

This is H4

This is H5
This is H6 - Smallest Heading

<p> - Paragraph

Purpose: Defines a paragraph of text.

This is a paragraph. It can contain multiple sentences and will automatically wrap to the next line when needed.

<strong> and <b> - Bold Text

Purpose: Make text bold. <strong> indicates importance, <b> is just styling.

This text is strong (important) and this is bold

<em> and <i> - Italic Text

Purpose: Make text italic. <em> indicates emphasis, <i> is just styling.

This text is emphasized and this is italic

<mark> - Highlighted Text

Purpose: Highlights text with a yellow background.

This is highlighted text for emphasis.

<small> - Smaller Text

Purpose: Displays smaller text.

Normal text and smaller text

<del> and <ins> - Deleted and Inserted Text

Purpose: Show deleted (strikethrough) and inserted (underlined) text.

This text is deleted and this text is inserted

<sub> and <sup> - Subscript and Superscript

Purpose: Display subscript and superscript text.

H2O (water formula) and E=mc2 (Einstein's equation)

<br> - Line Break

Purpose: Inserts a line break (self-closing tag).

First line
Second line after break

<hr> - Horizontal Rule

Purpose: Creates a horizontal line (self-closing tag).

Content below the line

4. Links and Media Tags

<a> - Anchor (Link)

Purpose: Creates hyperlinks to other pages or sections.

Visit Example.com

Jump to Text Tags section

Send an email

<img> - Image

Purpose: Embeds an image (self-closing tag).

<img src="image.jpg" alt="Description of image" width="300" height="200">

Note: Always include 'alt' attribute for accessibility!

<video> - Video

Purpose: Embeds video content.

<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>

<audio> - Audio

Purpose: Embeds audio content.

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Your browser does not support the audio tag.
</audio>
